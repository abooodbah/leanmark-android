# LeanMark for Android 0.3.0

LeanMark for Android 0.3.0 brings the reader of desktop LeanMark 0.8.0 to
the phone: the interface in Simplified Chinese, the full text column for
short documents on wide screens, and faster theme changes.

On Google Play this app is in a closed test. To join:
https://abooodbah.github.io/leanmark-android/

## What changed

- **Simplified Chinese.** The app shows its interface in Simplified
  Chinese when the phone's language is Simplified Chinese (for example
  zh-CN or zh-SG). The settings sheet has a new Language choice: System,
  English or 简体中文, remembered like the theme. The Chinese text is the
  desktop app's. Messages the desktop app does not translate stay in
  English.
- **Short documents on wide screens.** A document with fewer than two
  second- or third-level headings has no "On this page" list. On a screen
  1180 px wide or more, such as a tablet in landscape, its text was
  squeezed into a 220 px column. It now gets the Narrow, Wide or Full
  column.
- **Faster theme changes.** On a long document with diagrams a theme
  change takes about half as long. Diagrams are drawn again only when
  their colours change, and only once.
- **Repeated headings.** Documents with many repeated headings open
  faster, as in desktop 0.7.0.
- **Checking a download.** The APK and the bundle on this page carry a
  build provenance attestation. `gh attestation verify LeanMark-0.3.0.apk
  --repo abooodbah/leanmark-android` shows that the file was built by
  this repository's release workflow from the v0.3.0 tag. This is not
  code signing.

Settings saved by 0.2.0 have no language, so the app follows the phone,
and an English phone sees no change.

Still no permissions and no network.

## How it was measured

On an API 34 emulator without a GPU, in the CI budgets job, release builds
of 0.2.0 and of 0.3.0 measured in turns, in two runs (run 44330585001,
attempts 1 and 2):

- APK, all ABIs: 2,251,229 bytes for 0.2.0, 2,261,389 for 0.3.0 (10,160
  bytes more, mostly the Chinese strings in the reader page).
- Theme switch on a 1 MiB document with 11 diagrams, key to drawn:
  5,804 and 8,165 ms for 0.2.0, 3,158 and 4,388 ms for 0.3.0.
- Start time: simple.md drawn after a cold start, less an empty app's
  first frame: 172 and 432 ms for 0.2.0, 156 and 412 ms for 0.3.0. The
  phone budget is under 1 s from an empty app's start.
- Memory after the 1 MiB document, app and WebView renderer: 389,605 and
  397,726 KB for 0.2.0, 393,418 and 399,873 KB for 0.3.0 (0.5 to 1.0%
  more).
- The 1 MiB document drawn after a cold start: 1,499 and 2,715 ms for
  0.2.0, 1,736 and 2,655 ms for 0.3.0. Rotating it: 153 and 184 ms for
  0.2.0, 160 and 215 ms for 0.3.0. Both move by more than that between
  runs of the same build.
- Janky frames over ten swipes: 79% and 87% for 0.2.0, 88% and 88% for
  0.3.0. The emulator draws without a GPU, so this compares builds only.

The emulator has no GPU, so start time and smoothness on a phone are not
measured here; PROGRESS.md has the phone test.

## Known gaps

- The Chinese text has not been reviewed by a native speaker, as on the
  desktop. Traditional Chinese keeps English.
- Twelve of the app's own messages have no desktop translation and stay in
  English in a Chinese interface, for example the message shown when the
  app that shared a file has withdrawn access.
- Text inside Mermaid diagrams, the store listing and the website are in
  English.
- Checked on emulators (Android 8 with WebView 69, Android 14 with WebView
  113, and an Android 14 tablet), not on a real phone or tablet.
- Images next to the Markdown file and links to other local files are
  still not shown.

## Files

Each file has a `.sha256` next to it. `LeanMark-0.3.0.apk` is the build to
install. It is signed with the same release key as 0.2.0, so it installs
over 0.2.0.
